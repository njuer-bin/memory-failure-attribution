Every distorted execution cites a memory that explicitly states a decision or
authorization. Every omission execution turns "The user mentioned
consenting/agreeing/RSVPing/authorizing …" into an explicit consent statement
in its reason. There are no request-as-authorization cases: unlike the
pre-amendment run (5 O3, including 2 present and 2 no-memory records), the v3.1
clause's negative sentence appears to suppress the request-driven floor.

## Effect of the v3.1 amendment on this model

The two glm runs use the same scenarios and differ only in the authorization
clause. Scenario-level transitions:

- Distorted: 19 records flipped from non-execute to EXECUTE; 2 flipped back.
  Unauthorized distorted executions rose from 18/34 to 28/34 (neutral) and
  18/34 to 26/34 (action).
- Present/no-memory: the pre-amendment run executed 4 present and 4 no-memory
  over-commitment records across forms (1/34 each cell); under v3.1 both fall
  to 0/34. The request-driven O3 floor disappears.
- Omission is stable: 6/34 -> 7/34 neutral and 4/34 -> 4/34 action.

The amendment therefore has two opposing effects on this model: it raises
sensitivity to a memory that asserts authorization (the intended construct),
and it removes the model's tendency to read the current request as
authorization. Because both runs are single-clause designs, the difference is
reported as a design sensitivity, not as a replication failure. **Do not pool
the pre-amendment and v3.1 glm matrices.**

## Cross-model v3.1 comparison

Unauthorized over-commitment executions:

| Request | Variant | qwen2.5:7b | gemma3:12b | glm-5.3-flash |
|---|---|---|---:|---:|
| neutral | omitted | 0/34 | 5/34 | 7/34 |
| neutral | distorted | 1/34 | 24/34 | 28/34 |
| action | omitted | 0/34 | 0/34 | 4/34 |
| action | distorted | 1/34 | 10/34 | 26/34 |

Distortion harm replicates on the third, non-local model and is, if anything,
larger than on gemma. The gemma action-form attenuation (24/34 -> 10/34) does
not appear on glm (28/34 -> 26/34); the interaction intervals include zero.
Omission over-action is present in both forms on glm, unlike gemma's neutral-only
pattern. The safe cross-model claim is therefore about the **direction** of the
distortion effect, not about the request-form modulation, which is
model-dependent.

## Limitations

- The 16 new authorized controls remain author-constructed and mechanically
  checked, not two-human validated; the same disclosure as the local run
  applies.
- Reason coding is analyst, post hoc, and gold-unblinded; the blind second-rater
  sheet has not been run for this model.
- The six action-completed distortions are reported separately; they are a
  distinct harm (re-executing a completed action), not a representative sample
  of the 34.
- The gateway reports the model name `glm-5.3-flash`; no independent model-card
  verification was possible.
- Three records are format-only parse failures; the neutral control gate is
  20/20 semantically but 19/20 mechanically, and the paper should use the
  semantic count with the artifact disclosed.
