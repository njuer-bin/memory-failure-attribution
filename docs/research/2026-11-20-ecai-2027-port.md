# 2026-11-20 — ECAI 2027 port (7+1 pages) and artifact resync

Adapts the submission to ECAI 2027 (CCF-B, double-blind, non-ARR) under the
plan's 7-page body (Limitations inside) + 1-page references ceiling, with all
appendices externalised to a standalone supplementary PDF. Nothing here
changes the evidence; it repackages the existing artifacts for the new format.

   plus Study 2b unauthorized execution by request form across qwen2.5:7b,
   gemma3:12b, and glm-5.3-flash (v3.1), generated by
   `experiments/make_paper_figures.py` from the frozen analysis artifacts.
   `paper/figures/fig4_behavior.{pdf,png}` regenerated and copied into
   `paper/submission/figures/` and `paper/supplementary/figures/`.

   includes the glm-5.3-flash v3.1 aggregate tables (`study2b_glm_*`). The glm
   run *configuration* is deliberately excluded because it carries a gateway
   session identifier. 50 files, manifest rehashed, identifier scan clean.
3. **New ECAI build** in `paper/submission_ecai/`: `main.tex`, `appendix.tex`,
   `custom.bib`, `figures/`, a local `ecai.cls` stand-in, and `README.md`.
   Main body folds in Limitations and cites the glm v3.1 matrix directly (the
   earlier "no API model was tested" caveat is gone).
